## 📋 Overview

Tegel uses CSS utility classes applied to a wrapper element to toggle brand themes:

- `scania` — applies the scania theme
- `traton` — applies the traton theme

These classes trigger design tokens for background, text, icons, and components, allowing seamless switching between themes.

## 🛠️ Implementation

### 📍 Where to Apply the Class

- **Application-wide**: Apply the class (`scania` or `traton`) to the `<html>`, or top-level layout wrapper to theme the entire app.
- **Scoped to a Component**: You can also apply the class to a specific wrapper if only part of your interface should switch themes — useful for previews, widgets, or context-sensitive styling.

## ✅ Best Practices

1. **Default Theme**: The default fallback is Scania brand if none is specified, however we strongly advise to always set a default theme class (`scania`) on your root element
